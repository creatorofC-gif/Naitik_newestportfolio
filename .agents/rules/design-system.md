# Design System Rules

## Visual Identity

The portfolio uses a sophisticated:

- obsidian dark theme
- gold accent system
- architectural/technical aesthetic
- cinematic presentation
- high contrast
- restrained visual effects

The website should feel:

- intelligent
- engineered
- premium
- precise
- cinematic
- modern

---

## Avoid Generic Portfolio Design

Do not create layouts that resemble generic AI-generated portfolios.

Avoid:

- generic gradient blobs
- excessive glassmorphism
- random neon colors
- excessive rounded cards
- generic SaaS dashboards
- template-like hero sections
- unnecessary badges
- excessive glowing elements
- random floating shapes
- excessive gradients

---

## Visual Hierarchy

Every section must have:

1. Primary visual focus
2. Supporting information
3. Interaction
4. Secondary details

Not every element should compete for attention.

Use:

- spacing
- typography
- contrast
- scale
- positioning
- motion

to establish hierarchy.

---

## Color

Gold is an accent.

Do not make the entire interface gold.

Use gold for:

- important actions
- highlights
- active states
- system indicators
- architectural details
- important metadata

Maintain a dark obsidian foundation.

---

## Typography

Typography should feel editorial and technical.

Use strong hierarchy between:

- display headings
- section headings
- body text
- metadata
- technical labels

Avoid excessive oversized typography.

---

## Spacing

Prefer generous whitespace.

Do not fill every available space with content or effects.

Use consistent spacing tokens.

---

## Borders

Prefer subtle:

- 1px borders
- technical dividers
- thin grid lines
- restrained glow

Avoid heavy borders.

---

## Design Principle

The website should look expensive because of:

- composition
- typography
- spacing
- interaction
- restraint

not because every element has an effect.
